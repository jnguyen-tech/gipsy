# Gipsy's knowledge pack

Lessons Gipsy can look things up in (retrieval-augmented generation). Every
`## ` section is one searchable chunk, so keep each section about one idea and
under roughly 350 words.

All text here is original, written for this project. It is educational and is
not financial advice.

To add a lesson: create a new `.md` file with a `# Title` and `## ` sections,
then restart Gipsy Hub. The hub re-embeds only the sections that changed.

| File | What it covers |
| --- | --- |
| `tradingview.md` | Getting around TradingView: charts, timeframes, indicators, drawings, alerts, paper trading, Pine Script |
| `chart-basics.md` | Candlesticks, trend, support and resistance, volume, timeframes |
| `moving-averages.md` | SMA vs EMA, the EMA formula, 9/21 and 20/50/200, crossovers, pitfalls |
| `intermarket.md` | How gold, silver, the dollar, bonds and yields, crypto, stocks and housing relate |
| `risk-and-learning.md` | Risk management, position sizing, journaling, beginner mistakes, a learning path |
